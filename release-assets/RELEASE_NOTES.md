Music Vault Vanguard 8.12.1 baseline release.

This initial stable release establishes the private GitHub update channel for the CasaOS updater. The package is intentionally a no-op because version 8.12.1 is already installed. Future releases will contain a complete transactional installer and a higher semantic version.

The release workflow builds the ZIP and SHA-256 manifest automatically from release-assets/package/ whenever release assets are updated on main.
