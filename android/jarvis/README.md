# JARVIS T88 Android App 1.0.0

Landscape client for the self-hosted JARVIS 5.2 server at `http://100.83.43.110:8790/`.

- Native Android push-to-talk microphone button (press to speak; no always-on wake word).
- Native Text-to-Speech for JARVIS spoken replies.
- Image picker for JARVIS vision uploads.
- Tailscale shortcut, editable server URL, and automatic retry after returning from Tailscale.
- No API key or JARVIS access key is embedded in the APK. Enter the server-issued JARVIS key when the app prompts you.
