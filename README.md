# Music Vault Updates

Public release channel for Music Vault Vanguard on CasaOS.

- Repository: `Osm1i/music-vault-updates`
- Stable release workflow: `.github/workflows/publish-music-vault-release.yml`
- Release packages are syntax-checked, regression-tested, checksummed, ZIP-verified and gated by a simulated install plus rollback before publication.
- Music, database, profiles, playlists, favorites and server configuration remain on the user's CasaOS host.

Latest stable release: **9.27.0** — Reliability Center, verified database backups, adaptive/retryable YouTube downloads, non-destructive library diagnostics, profile-owned playlist deletion and clear YouTube sign-in challenge guidance.
